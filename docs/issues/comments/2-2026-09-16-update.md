## Implementation & Verification Summary

All findings from the security review have been addressed, verified, and documented:

1. **Private Runtime Directory (`0700`)**:
   - Runtime root placed at `$XDG_RUNTIME_DIR/omarchy-moergo-companion` with fallback to mode-0700 `/tmp/omarchy-moergo-${UID}`.
   - Enforces directory ownership by `getuid()`, non-symlink verification, and strict permissions (`0700`).
   - Synced `Service.qml` dynamic binding to the identical secure runtime path.

2. **Symlink Defense & Hardened PID Locking (`watcher.rs`)**:
   - Relocated PID lock to `<runtime_dir>/glove80_watcher.pid`.
   - Opened using `libc::O_NOFOLLOW` without pre-lock truncation.
   - Acquires `flock(LOCK_EX | LOCK_NB)` before truncation.
   - Verifies regular file ownership post-lock before calling `file.set_len(0)` and writing PID.

3. **Atomic Replacement with Secure Tempfiles (`watcher.rs` & `status.rs`)**:
   - Replaced predictable `.tmp` paths and `fs::write` with `runtime::atomic_write`.
   - Generates unguessable temporary files (`NamedTempFile::new_in`) with mode `0600` in the user-private directory and atomically renames them over destination.
   - Explicitly rejects existing destination symlinks before replacement.
   - Migrated `status.rs` battery notification state to `<runtime_dir>/glove80_battery_notified.json`.

4. **Binary Provenance & Automated Release Compilation**:
   - Untracked and removed committed ELF binaries from git; updated `.gitignore` to ignore `bin/`.
   - Updated `install.sh` and `justfile` to compile from locked source (`cargo build --release --locked`).
   - Added `.github/workflows/ci.yml` for automated CI testing and verification.
   - Added `.github/workflows/release.yml` triggered on Git tags (`v*`) to automatically compile release binaries from `Cargo.lock`, generate `SHA256SUMS`, and publish release assets with cryptographic verification instructions.

5. **Testing & Verification**:
   - 6 new security tests added in `keymap-parser/tests/security_test.rs` (35 total tests passing across all suites).
   - End-to-end integration verified with Quickshell and watcher execution.
   - Code review completed and documented in [docs/issues/comments/2-code-review.md](comments/2-code-review.md).
